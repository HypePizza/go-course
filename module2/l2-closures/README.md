# Модуль 2 · Урок 2. Функции как значения и замыкания

**Время:** 2,5–4 часа на весь урок. Пример и разбор типов займут примерно 25–40 минут, задание 1 — 25–40 минут, задание 2 — 40–60 минут, задание 3 с проверкой — 60–100 минут. Можно останавливаться после каждого блока. **Цель:** передать функцию как аргумент и написать функцию, которая помнит результат предыдущего вызова.

## Зачем это нужно

В прошлом уроке ты передавал числа в `stats`. В Go аргументом может быть и действие. Например, один и тот же код обработки измерений может принимать разные правила проверки температуры. Порог одного датчика равен 70 градусам, другого — 90. Каждому можно передать своё правило с уже заданным порогом.

## Пример

```go
package main

import "fmt"

func above(limit int) func(int) bool {
	return func(value int) bool {
		return value > limit
	}
}

func check(value int, rule func(int) bool) bool {
	return rule(value)
}

func main() {
	hot := above(70)
	fmt.Println(check(75, hot))
	fmt.Println(check(70, hot))
}
```

Вывод — `true`, затем `false`. Проследи первый вызов:

1. `above(70)` создаёт функцию и возвращает её. Переменная `hot` получает значение типа `func(int) bool`. Сравнения на этом шаге ещё нет.
2. `check(75, hot)` передаёт число и саму функцию. Скобки у имени `hot` здесь не нужны.
3. Внутри `check` выражение `rule(value)` вызывает переданную функцию. Она сравнивает `75` с переменной `limit`, доступ к которой сохранился после завершения `above`. Такая функция, использующая переменные из окружающей области, называется **замыканием**.

Замыкание сохраняет доступ к **переменной**. Если при вызове оно изменит эту переменную, следующий вызов того же замыкания увидит новое значение. Отдельный вызов `above(90)` создаст свою переменную `limit`.

### Как читать сигнатуру

Прочитай `func above(limit int) func(int) bool` слева направо. Первые скобки описывают аргументы самой `above`. Всё после них — тип её результата. У возвращённой функции свой аргумент и свой результат.

Закрой пример и запиши тип каждого выражения: `above`, `above(70)`, `above(70)(75)`. Затем проверь себя через `fmt.Printf("%T\n", выражение)`, подставляя по одному выражению. Объясни, в какой момент выбирается порог и в какой момент появляется показание для сравнения.

## Сравнение с C и Python

В C правило сравнения можно передать через указатель на функцию. Для настраиваемого порога в стандартном C обычно отдельно передают значение порога или указатель на данные. В Go порог доступен внутри возвращённой функции по имени `limit`.

В Python похожую функцию можно определить внутри `above` через `def` и вернуть по имени. Чтобы переприсваивать переменную внешней функции, в Python нужен `nonlocal`. В Go достаточно обычного присваивания или `+=`.

## Типичные ошибки

- `check(75, hot(75))` не скомпилируется. Выражение `hot(75)` уже вернуло `bool`, а параметру `rule` нужна функция.
- Если объявить переменную счётчика внутри тела возвращённой функции, каждый вызов начнётся с новой переменной. Выбирай место объявления по тому, как долго должно жить значение.
- `var rule func(int) bool` объявляет переменную с начальным значением `nil`. Если вызвать её до присваивания функции, во время выполнения произойдёт паника.
