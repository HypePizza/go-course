# Модуль 2 · Мини-проверка № 2

**Прогресс:** теория — 5 из 5. Осталось сдать на ревью практическую задачу «Учёт замеров».

## Теория

При повторении сначала дай прогноз, затем объясни его одной-двумя фразами.

1. **Когда читается значение в defer?** Переменная содержит слово «до». Первым регистрируют отложенное замыкание A, которое печатает переменную при выполнении. Вторым регистрируют отложенный вызов B, передавая ему текущее значение аргументом. Затем переменной присваивают «после», и функция завершается. В каком порядке появятся A и B и какое слово напечатает каждая?
2. **Кто разделяет состояние накопителя?** Накопитель A начинает с 10. Его копируют в B. Для C создают отдельный накопитель с начальной суммой 10. Через B прибавляют 4. Что вернут A и C, если каждому передать ноль? Почему?
3. **Что получит вызывающая функция после recover?** Обработчик запаниковал. В runStep отложенная функция перехватила панику, но пропустила присваивание ошибки именованному результату. До вызова обработчика этот результат был равен nil. Что получит main и какой вывод сделает о шаге?
4. **Как iota влияет на повторяющееся выражение?** В блоке констант на первой строке задана единица, сдвинутая влево на iota позиций. На второй и третьей строках указаны только имена констант. Какие значения получат все три константы и почему?
5. **Куда передают управление break и continue?** Цикл перебирает числа 1, 2 и 3. Внутри switch для 1 выполняется break, для 2 — continue, для 3 подходящей ветки нет. Сразу после switch, всё ещё внутри цикла, печатается текущее число. Какие числа появятся на экране? Куда перейдёт выполнение в каждом из первых двух случаев?

## Практика · Учёт замеров

Программа получает показания в виде строк. Обработай по очереди «5», «abc» и «-2». Даже неудачное чтение считается попыткой. После ошибки программа продолжает обрабатывать оставшиеся показания.

### Условие

- Функция обработки одного замера принимает строку и два действия: учесть корректное целое число и отметить завершение попытки.
- При успешном разборе функция передаёт число первому действию и возвращает nil. При ошибке разбора она возвращает ошибку вызывающему коду.
- Второе действие должно сработать ровно один раз при любом из этих исходов. Примени defer, чтобы это правило выполнялось при обоих выходах.
- Используй замыкания для накопления суммы и подсчёта попыток. В main подсчитай полученные ошибки и выведи итоги серии.

### Самопроверка

| После обработки | Сумма | Завершено попыток | Получено ошибок |
|---|---:|---:|---:|
| «5» | 5 | 1 | 0 |
| «abc» | 5 | 2 | 1 |
| «-2» | 3 | 3 | 1 |

Промежуточные строки помогают найти ошибку. Для итогового вывода достаточно трёх значений: **сумма 3, попыток 3, ошибок 1**.
