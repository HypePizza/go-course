# Урок 3. `if`, `for` и `switch`

> Модуль 1 «Старт» · Go 1.27.1 · macOS

## Зачем это нужно

Любая логика — проверить ввод, обойти записи из базы, выбрать обработчик по команде — строится на условиях и циклах. В Go их намеренно мало: один `if`, один `for` и один `switch`. Зато у каждого есть приёмы, которые вы будете видеть в каждом файле реального проекта, особенно `if err := ...; err != nil`.

## Объяснение

### `if`

```go
if x > 10 {
	fmt.Println("много")
} else if x > 0 {
	fmt.Println("немного")
} else {
	fmt.Println("ничего")
}
```

- Скобки вокруг условия **не пишутся**, фигурные скобки **обязательны** даже для одной строки.
- Условие должно быть строго `bool`: `if x { ... }` для `int` не скомпилируется.

**`if` с коротким оператором** — главная идиома Go:

```go
if n, err := strconv.Atoi("42"); err != nil {
	fmt.Println("не число:", err)
} else {
	fmt.Println("число:", n)
}
// здесь n и err уже не видны
```

Сначала выполняется оператор до `;`, потом проверяется условие. Переменные живут только внутри `if`/`else` — не засоряют функцию. Подробно про ошибки будет в модуле 4, а пока запомните форму.

### `for` — единственный цикл

```go
// 1. Классический, как в C
for i := 0; i < 3; i++ { ... }

// 2. Как while
for n < 100 { ... }

// 3. Бесконечный
for { ... }

// 4. range по целому числу (Go 1.22+): i = 0, 1, 2
for i := range 3 { ... }
```

Позже добавится `range` по слайсам, строкам, map и каналам — это та же форма 4.

`break` выходит из цикла, `continue` переходит к следующей итерации. Чтобы выйти сразу из **внешнего** цикла, используют метку:

```go
outer:
	for i := range 3 {
		for j := range 3 {
			if i*j == 2 {
				break outer // выход из обоих циклов
			}
		}
	}
```

### `switch`

```go
switch day {
case 1, 2, 3, 4, 5: // несколько значений в одном case
	fmt.Println("будни")
case 6, 7:
	fmt.Println("выходные")
default:
	fmt.Println("нет такого дня")
}
```

- `break` в конце `case` **не нужен** — выполняется только один подходящий `case`.
- Если очень нужно провалиться в следующий `case`, есть ключевое слово `fallthrough`, но в реальном коде оно почти не встречается.

**`switch` без условия** — читаемая замена длинной цепочки `if-else`:

```go
switch {
case temp < 0:
	fmt.Println("мороз")
case temp < 20:
	fmt.Println("прохладно")
default:
	fmt.Println("тепло")
}
```

Условия проверяются сверху вниз, срабатывает первое истинное.

### Полный пример

**`main.go`** (запуск: `go mod init flow && go run .`)

```go
package main

import (
	"fmt"
	"strconv"
)

func main() {
	// if с коротким оператором: n и err видны только внутри if/else
	if n, err := strconv.Atoi("42"); err != nil {
		fmt.Println("не число:", err)
	} else if n%2 == 0 {
		fmt.Println(n, "чётное")
	} else {
		fmt.Println(n, "нечётное")
	}

	// Классический for, как в C
	for i := 0; i < 3; i++ {
		fmt.Print(i, " ")
	}
	fmt.Println()

	// for как while
	n := 1
	for n < 100 {
		n *= 2
	}
	fmt.Println("n =", n)

	// range по целому числу (Go 1.22+): i = 0, 1, 2
	for i := range 3 {
		fmt.Print(i, " ")
	}
	fmt.Println()

	// Бесконечный цикл с break и continue
	count := 0
	for {
		count++
		if count%2 == 0 {
			continue // чётные пропускаем
		}
		if count > 7 {
			break // выходим из цикла
		}
		fmt.Print(count, " ")
	}
	fmt.Println()

	// switch: break не нужен, в case можно перечислить несколько значений
	day := 6
	switch day {
	case 1, 2, 3, 4, 5:
		fmt.Println("будни")
	case 6, 7:
		fmt.Println("выходные")
	default:
		fmt.Println("нет такого дня")
	}

	// switch без условия — замена длинной цепочки if-else
	temp := 18
	switch {
	case temp < 0:
		fmt.Println("мороз")
	case temp < 20:
		fmt.Println("прохладно")
	default:
		fmt.Println("тепло")
	}

	// Метка позволяет выйти сразу из внешнего цикла
outer:
	for i := range 3 {
		for j := range 3 {
			if i*j == 2 {
				fmt.Println("нашли:", i, j)
				break outer
			}
		}
	}
}
```

Вывод:

```
42 чётное
0 1 2 
n = 128
0 1 2 
1 3 5 7 
выходные
прохладно
нашли: 1 2
```

## Сравнение с C и Python

| | C | Python | Go |
|---|---|---|---|
| Скобки в условии | `if (x > 0)` | `if x > 0:` | `if x > 0 {` |
| Циклы | `for`, `while`, `do-while` | `for`, `while` | только `for` |
| Перебор `0..n-1` | `for (i = 0; i < n; i++)` | `for i in range(n)` | `for i := range n` |
| Тернарный оператор | `a ? b : c` | `b if a else c` | **нет**, пишите `if` |
| Провал в `switch` | по умолчанию, нужен `break` | — (`match` не проваливается) | **нет**, по умолчанию; есть `fallthrough` |
| Число как условие | `if (n)` работает | `if n:` работает | **ошибка**, нужно `if n != 0` |

Привычки, которые будут мешать:
- **Из C:** ставить `break` в каждом `case` (лишнее) и искать тернарный оператор (его нет специально — ради читаемости).
- **Из Python:** писать `if items:` или `if n:` — в Go условие только `bool`.

## Типичные ошибки

1. **`break` внутри `switch` внутри `for`** выходит из `switch`, а **не из цикла**. Одна из самых коварных ошибок — разберёте в задании 3.
2. **Переменная из `if`-инициализатора нужна после `if`.** `if n, err := ...` — после `}` переменной `n` уже нет. Если она нужна дальше, объявите её до `if`.
3. **Бесконечный цикл без выхода.** `for n < 100 { ... }`, где `n` внутри не меняется, — программа просто зависнет.
4. **Скобка `else` на новой строке.** `}` и `else` должны быть на одной строке: `} else {`. Иначе — синтаксическая ошибка (та же автоматическая `;`, что в уроке 1).

## Задания

### 1. FizzBuzz
Классика собеседований. Напечатайте числа от 1 до 30, но вместо чисел, кратных 3, печатайте `Fizz`, кратных 5 — `Buzz`, кратных и 3, и 5 — `FizzBuzz`. Используйте `switch` без условия. Подумайте, в каком порядке должны идти `case` и почему.

### 2. Простое число
Утилита командной строки: `go run . 97` печатает, простое ли число, и все его делители.

```
$ go run . 12
12 — составное, делители: 1 2 3 4 6 12
$ go run . 97
97 — простое
$ go run . abc
ошибка: "abc" — не целое число
$ go run .
использование: go run . <число>
```

Требования:
- аргумент берите из `os.Args`, переводите в число через `strconv.Atoi` с идиомой `if ... ; err != nil`;
- при ошибке печатайте сообщение и завершайте программу с кодом `1` — найдите нужную функцию в пакете `os`;
- подумайте, как обработать `0`, `1` и отрицательные числа.

### 3. Ловушка с `break`
Автор хотел, чтобы цикл остановился на первом отрицательном числе. Предскажите вывод, **не запуская**, потом проверьте. Объясните, что происходит, и исправьте код **двумя разными способами**.

```go
package main

import "fmt"

func main() {
	for i := range 10 {
		v := 5 - i*2 // 5, 3, 1, -1, -3, ...
		switch {
		case v < 0:
			fmt.Println("отрицательное, стоп")
			break
		default:
			fmt.Println(v)
		}
	}
}
```
