# Урок 2. Переменные, константы, `iota`, базовые типы и нулевые значения

> Модуль 1 «Старт» · Go 1.27.1 · macOS

## Зачем это нужно

Порт сервера, таймаут, имя пользователя, уровень логирования — всё это переменные и константы. Строгие типы Go ловят ошибки ещё на этапе компиляции, а `iota` используется в каждом втором проекте для перечислений: статусы заказа, уровни логов, роли пользователей.

## Объяснение

### Объявление переменных

```go
var port int = 8080    // полная форма
var host = "localhost" // тип выводится из значения
timeout := 30          // короткая форма, только внутри функций

var (                  // блок объявлений
	user  = "admin"
	debug = false
)

a, b := 1, 2           // несколько сразу
a, b = b, a            // обмен значениями без временной переменной
```

Когда что использовать:
- внутри функций — почти всегда `:=`;
- `var x T` — когда нужно нулевое значение («объявить, но пока не заполнять»);
- на уровне пакета (вне функций) — только `var`, `:=` там запрещён.

### Нулевые значения

В Go **не бывает неинициализированных переменных**. Если значение не задано, переменная получает нулевое значение своего типа:

| Тип | Нулевое значение |
|---|---|
| `int`, `float64` и другие числа | `0` |
| `bool` | `false` |
| `string` | `""` |
| указатели, слайсы, map, каналы, функции, интерфейсы | `nil` |

### Базовые типы

| Тип | Что это |
|---|---|
| `int`, `uint` | целые; на 64-битных системах — 64 бита. **Используйте `int` по умолчанию** |
| `int8` … `int64`, `uint8` … `uint64` | целые фиксированного размера — когда размер важен (протоколы, бинарные форматы) |
| `float64`, `float32` | дробные; по умолчанию `float64` |
| `bool` | `true` / `false` |
| `string` | неизменяемая строка в UTF-8 |
| `byte` | псевдоним `uint8` — один байт |
| `rune` | псевдоним `int32` — один символ Unicode (подробно в модуле 2) |

### Явное приведение типов

Go **никогда не приводит типы сам**. Даже `int` и `int64` нельзя сложить без явного преобразования:

```go
var a int = 10
var b int64 = 20
sum := int64(a) + b      // так можно
avg := float64(sum) / 3  // 6.666...
fmt.Println(sum / 3)     // 6 — деление целых отбрасывает дробь
```

### Константы и `iota`

```go
const appName = "hello" // нетипизированная константа

// iota — счётчик внутри блока const: 0, 1, 2, ...
type LogLevel int // свой тип на основе int (подробно в модуле 3)

const (
	Debug LogLevel = iota // 0
	Info                  // 1 — выражение повторяется автоматически
	Warn                  // 2
	Error                 // 3
)

const (
	_  = iota             // 0 — пропускаем через _
	KB = 1 << (10 * iota) // 1 << 10 = 1024
	MB                    // 1 << 20
	GB                    // 1 << 30
)
```

Константы вычисляются **на этапе компиляции**, поэтому значением может быть только то, что известно заранее: числа, строки, `bool`. Вызвать функцию в `const` нельзя.

**Нетипизированные константы** хранятся с высокой точностью и получают тип только при использовании. Поэтому `const big = 1 << 100` компилируется, а `var x int = big` — уже нет: в `int` такое не помещается.

### Полный пример

**`main.go`** (запуск: `go mod init vars && go run .`)

```go
package main

import "fmt"

// Уровень логирования — свой тип на основе int
type LogLevel int

const (
	Debug LogLevel = iota // 0
	Info                  // 1
	Warn                  // 2
	Error                 // 3
)

const (
	_  = iota             // 0 пропускаем
	KB = 1 << (10 * iota) // 1 << 10 = 1024
	MB                    // 1 << 20
	GB                    // 1 << 30
)

const appName = "hello" // нетипизированная константа

func main() {
	// Три способа объявить переменную
	var port int = 8080
	var host = "localhost" // тип выводится из значения
	timeout := 30          // короткое объявление, только внутри функций

	// Нулевые значения: переменная без инициализации никогда не содержит мусор
	var count int
	var ratio float64
	var ok bool
	var name string

	fmt.Println(appName, host, port, timeout)
	fmt.Printf("%v %v %v %q\n", count, ratio, ok, name)
	fmt.Printf("%T %T %T\n", port, ratio, Info)
	fmt.Println(Warn, KB, MB, GB)

	// Явное приведение типов обязательно
	var a int = 10
	var b int64 = 20
	sum := int64(a) + b
	avg := float64(sum) / 3
	fmt.Println(sum, avg, sum/3)
}
```

Вывод:

```
hello localhost 8080 30
0 0 false ""
int float64 main.LogLevel
2 1024 1048576 1073741824
30 10 10
```

Полезные глаголы `fmt.Printf`: `%v` — значение в формате по умолчанию, `%T` — тип, `%d` — целое, `%.2f` — дробное с двумя знаками, `%q` — строка в кавычках (видно пустую строку).

## Сравнение с C и Python

- **C:** локальная переменная без инициализации содержит мусор — классический источник багов. В Go это невозможно, всегда есть нулевое значение.
- **C:** `int` + `long` или `int` + `double` приводятся неявно. В Go — ошибка компиляции, пишите `float64(x)`. Сначала раздражает, зато нет тихой потери точности.
- **C:** размер `int` зависит от компилятора и платформы. В Go `int32`/`int64` всегда ровно такого размера, а `int` на всех современных 64-битных системах — 64 бита.
- **Python:** переменная может сменить тип (`x = 1`, потом `x = "a"`). В Go тип фиксируется навсегда при объявлении.
- **Python:** `7 / 2 == 3.5`. В Go, как в C, `7 / 2 == 3` для целых.
- **Python и C:** перечислений через `iota` нет; ближайшее — `enum` в C и `enum.Enum` в Python.

## Типичные ошибки

1. **`:=` вне функции.** На уровне пакета работает только `var`.
2. **`:=` без новой переменной.** `x := 1`, потом `x := 2` в той же области — ошибка `no new variables on left side of :=`. Для присваивания используйте `=`.
3. **Затенение (shadowing).** `:=` во вложенном блоке создаёт **новую** переменную с тем же именем, а внешняя не меняется. Это одна из самых частых тихих ошибок в Go — разберёте её в задании 3.
4. **Смешивание типов в выражении.** `int * float64` не компилируется — приводите явно.
5. **Переполнение.** `var x int8 = 127; x++` даёт `-128` без всякой ошибки во время выполнения. А вот переполнение константы (`var x int8 = 200`) компилятор поймает.

### 3. Найди ошибки
